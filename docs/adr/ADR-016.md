# ADR-016: Execution Session Encapsulates Runtime Outcome

## Decision
The runtime returns an `ExecutionSession` instead of exposing raw subprocess results. The `ExecutionSession` combines:
1. Runtime outcome (exit_code, timed_out, duration_ms)
2. Canonical evidence (`BehaviorTranscript`)

This cleanly separates execution metadata from behavioral evidence while giving downstream components a single protocol object to consume.
