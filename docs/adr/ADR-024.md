# ADR-024: Architecture Freeze v1.0

## Status

Accepted

---

## Decision

The following architectural subsystems are frozen.

- Gateway Framework
- Intake Pipeline
- Static Analysis
- Policy Engine
- Runtime Framework
- Sensor Framework
- Observation Framework
- Behavior Protocol

Future work shall extend the system through
existing extension points.

Architectural redesign requires explicit review.

---

## Motivation

Nebula has reached a stable architecture suitable
for continued security engineering.

Future development shall prioritize

- isolation
- sandbox security
- execution correctness
- consensus

rather than structural redesign.
