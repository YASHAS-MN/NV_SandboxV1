# ADR-029: Network Sensor Uses Userspace Interception

## Status
Accepted

## Decision
The `NetworkSensor` intercepts outbound socket connections via a `sitecustomize.py`
shim written into the workspace directory before execution begins.

The shim monkey-patches `socket.socket.connect()` at the Python level and logs all
connection attempts to a JSON sidecar file in the workspace. After execution the sensor
reads the sidecar, publishes `NETWORK_CONNECT` events to the `ObservationBus`, and
cleans up both files.

## Rationale
- Low-level approaches (eBPF, raw sockets, `ptrace`) require OS privileges not
  available on standard node hardware.
- The userspace approach is deterministic, privilege-free, and scoped correctly to
  interpreted script runtimes — the same boundary enforced throughout this architecture.

## Constraint
This sensor only captures connections made through Python's `socket` API. Native binary
connections bypass this layer entirely. This limitation is structural and intentional —
native binaries are outside the v1.x sandbox scope.
