# Canonical Behavior Transcript Specification (CBTS)

Version: 1.0

## Purpose

The CBTS is the canonical protocol artifact generated by Nebula's
Execution Runtime.

Its purpose is to provide a deterministic, reproducible,
implementation-independent description of observed execution behavior.

The transcript contains observations only.

It never classifies behavior as benign or malicious.

Those interpretations belong to higher protocol layers.
