# Nebula Architecture v0.1.0

This document describes the finalized architecture of Sprint 1 of the Nebula Protocol and Validator Suite.

## Overview

Nebula captures, records, and serializes execution transcripts deterministically, separating consensus-critical state validation from node-local execution metadata.

```
                    Asset
                      │
                      ▼
             Execution Engine
                      │
      ┌───────────────┴───────────────┐
      │                               │
      ▼                               ▼
Behavior Recorder              Filesystem Sensor
      │                               │
      └───────────────┬───────────────┘
                      ▼
          Behavior Transcript
            ├── Evidence Layer (Consensus Hashed)
            └── Metadata Layer (Node-Local Runtime)
                      │
                      ▼
        Canonical JSON Serializer
```

## Key Components

### 1. Execution Engine
The `ExecutionEngine` coordinates the isolation and execution of untrusted code. It sets up temporary sandboxed environments, initiates recording, launches subprocesses, and delegates change detection to sensors.

### 2. Behavior Recorder
The `BehaviorRecorder` acts as the single source of truth for constructing the execution transcript. It processes incoming event streams, assigns sequential indices, and pairs them with execution metadata (like elapsed time).

### 3. Sensors
Sensors observe specific facets of the environment during execution.
- **Filesystem Sensor**: Captures mutations (creations, deletions, and updates) inside the target workspace by comparing snapshot hashes before and after execution.

### 4. Behavior Transcript
The `BehaviorTranscript` houses two distinct layers:
- **Evidence Layer (Consensus-Critical)**: The sequence of events (`Event`), including action types, payloads, and identifiers. Hashing this layer is guaranteed to be 100% deterministic across different validators.
- **Metadata Layer (Node-Local)**: Nondeterministic environmental diagnostics (`RuntimeEventMetadata`), such as wall-clock execution time.

### 5. Canonical JSON Serializer
The `TranscriptSerializer` converts the consensus evidence layer into stable, deterministic, sorted JSON strings, facilitating cryptographic hash validation.
