# Nebula

Nebula repository structure.

## Repository Layout

- **`.github/workflows/`**: CI/CD workflows and automated pipelines.
- **`docs/`**: Project documentation including architecture, protocol specifications, ADRs, meetings, and sprints.
- **`sandbox/`**: Experimental environment for testing code and tools safely.
- **`validator/`**: Components related to validator logic and execution.
- **`shared/`**: Common libraries, utilities, and helper code shared across components.
- **`marketplace/`**: Marketplace integration or smart contract components.
- **`experiments/`**: Research-focused code, prototyping, and benchmarks.
- **`tests/`**: Integration and unit testing suite.
- **`tools/`**: Internal development tools and CLI utilities.
- **`scripts/`**: Convenience shell/Python scripts.
